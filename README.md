Навчальний адаптивний вебпроєкт для дисципліни «Технології веб-розробки та дизайну».

Автор: Максим Педич, група ПП-21. 2026 рік.

## Живі версії

- Репозиторій: https://github.com/lumencompanyua/gurman-info

## Запуск

Запустіть локальний HTTP-сервер у цій папці (`python -m http.server 8776 --bind 127.0.0.1`) і відкрийте http://127.0.0.1:8776. Для шрифтів Google та бібліотек галереї потрібен інтернет; основні блоки мають запасні шрифти й працюють без бібліотек. Сайт не надсилає персональні дані.

## Реалізовано

- семантична HTML5-структура та адаптивний CSS;
- каталог із фільтрами;
- віджет підбору пари «сир + вино»;
- форма з клієнтською валідацією;
- Swiper і Fancybox через CDN із перевіркою наявності бібліотек;
- SVG-логотип та набір SVG-іконок;
- базові SEO-метадані й доступність;
- GitHub Actions workflow для перевірки структури та публікації Pages.

## Редакція лабораторних №3–6 від 21.10.2026

`index.html` — сайт; `design-system.html` — локальна дизайн-система. У `assets` є редаговані SVG: `sitemap.svg`, `wireframe-desktop.svg`, `wireframe-mobile.svg`.

Наданий ролик PixVerse: 6,041667 с, 1024 × 592, 24 кадри/с. На сайті використано версію без аудіо та без позначки PixVerse. Позначку прибрано локальним відновленням фону, відео повторно закодовано у H.264 зі збереженням розмірів, частоти кадрів і тривалості. Оригінал залишено окремо. Відтворення одноразове, без loop. Після завершення плавно з’являється погоджене чисте фінальне фото. Кнопка «Завершити вступ» дозволяє перейти до нього раніше. За зменшення руху в системі відео не завантажується. Прокручування не запускає вступ заново; перезавантаження сторінки запускає його з початку.

Перевірено 1440, 768, 375 і 320 px без горизонтального переповнення; сітку каталогу 4 / 2 / 1 / 1; меню, закриття Escape, фільтри, підбір і локальну валідацію форми. Підтверджено один h1, main, header та footer і наявність alt у всіх img.

Товари умовні. Мапа, профіль і збереження пар — план розвитку.

Figma: https://www.figma.com/design/minnVc79WpCXVNTmFLSgxd

Кольорові змінні та компоненти UI Kit оновлено. Подальший контрольний експорт і повну синхронізацію каркасів зупинив ліміт Figma MCP Starter. Актуальні локальні схеми й дизайн-система збережені разом із сайтом; вони не позначаються як експорт із Figma.

## Лабораторна №7 — повноцінний лендинг (10.11.2026)

Структура: Header → Hero → Переваги → Каталог → Підбір пари → Порада сомельє (YouTube + інформер погоди) → Галерея → Про проєкт → FAQ → CTA → Контакти з картою → Footer.

- Нові блоки зверстано утилітами Tailwind CSS 3.4 (`assets/tailwind.css`, зібрано з `tailwind.input.css` і `tailwind.config.js`; preflight вимкнено, щоб не ламати стилі ЛР3–6). Кольори Tailwind беруться зі змінних `:root` дизайн-системи.
- YouTube-відео «Про вино за 100 секунд. Поєднання вина та їжі» (канал «Громадське телебачення: Черкаси») — `iframe` з `aspect-video`, `title`, `loading="lazy"`.
- Google Maps: головний корпус НУ «Львівська політехніка» (код із «Поділитися → Вбудувати карту»), обгортка 4:3 / 16:9.
- `weather-widget.js` — динамічний інформер: поточна погода у Львові з Open-Meteo (без ключа) і порада температури подачі.
- Pick Element: компактні картки переваг на телефоні (`max-sm:*`), виразніша головна CTA з видимим `focus-visible`.

Перезбірка стилів: `npx tailwindcss@3.4.17 -c tailwind.config.js -i tailwind.input.css -o assets/tailwind.css --minify`.

Опубліковано на Netlify: https://gurman-info.netlify.app (сайт `gurman-info`; оновлюється автоматично після push у `main`).

## Лабораторна №9 — форма зворотного зв'язку та клієнтська валідація

- Форма в секції «Контакти»: ім'я, email, телефон, тема, повідомлення, згода; `label for` + `id`, `aria-describedby`, `aria-invalid`.
- Tailwind-стани полів: normal, focus (`focus-visible:ring`), error (`border-red-500` + текст під полем), success (`border-green-500`); на телефоні одна колонка, від `md` — дві.
- Валідація в `assets/js/validation.js` (Vanilla JS): RegEx для імені, email і телефону `^\+380\d{9}$`; перевірка на `blur`, `input` після першої взаємодії й на `submit`.
- Edge Cases телефону: `0501234567`, `380…`, номер із пробілами чи дужками приводяться до `+380XXXXXXXXX`; літери та зайві цифри дають зрозумілу помилку.
- Модальне вікно успіху: показується лише після валідації, закривається кнопкою, `Escape` або кліком по фону; фокус повертається на кнопку «Надіслати». Реального надсилання немає.

## Лабораторна №10 — медіакомпоненти та JS-бібліотеки через CDN

- Галерея «Атмосфера дегустації»: Swiper.js 11 — 6 слайдів, `loop`, автоплей 3,5 с з паузою при наведенні, стрілки, клікабельна пагінація, брейкпоінти 1 / 2 / 3 слайди (320 / 768 / 1024 px), керування клавіатурою.
- Fancybox 5: усі фото в альбомі `data-fancybox="gurman-gallery"`, перехід `fade`, наближення до 3×, українські підписи кнопок.
- Typed.js 2.0.12 у Hero: ефект друку з парами з віджета підбору; для екранних читачів — статичний текст, при `prefers-reduced-motion` анімація вимкнена.
- CSS бібліотек підключено в `<head>`, JS — перед `</body>` з `defer`; ініціалізація в `assets/js/media.js` після `DOMContentLoaded`.

## Лабораторна №11 — інтерактивний віджет і Edge Cases

- Секція «Калькулятор дегустації» (`#calculator`): 5 параметрів — гості (1–50), формат, тривалість (1–5 год), види сиру (3–7), супровід; миттєвий перерахунок сиру, вина й супроводу.
- Норми: сир 50 / 100 / 180 г на гостя (аперитив / дегустація / вечеря), вино — 2 келихи за першу годину й по 1 за кожну наступну, 5 келихів у пляшці, супровід 40 г на гостя.
- `assets/js/widget.js`: захист на рівнях HTML5, JS і виводу — без NaN, Infinity, від'ємних і дробових гостей; значення, змінені в DevTools, повертаються в межі; без елемента DOM віджет не падає; кілька екземплярів працюють незалежно, глобальних змінних немає.
- Журнал QA: `Матеріали/ЛР11_QA` (перша версія лише з Happy Path і результати стрес-тестів обох версій).

## Лабораторна №12 — аудит Lighthouse, оптимізація та CI/CD

- Гілка `performance-audit`, злита в `main` після перевірок.
- Продуктивність: адаптивні зображення (`srcset`, версії 800 px), відео Hero вантажиться лише після `load` (на телефонах — за кнопкою), шрифти Manrope і Playfair Display розміщено в `assets/fonts`, Swiper і Fancybox підвантажуються при наближенні до галереї, «фасад» YouTube замість iframe до натискання, шрифти Google без блокування відображення, з `styles.css` прибрано 60 мертвих правил.
- Доступність: стрілки слайдера 48×48 px. SEO: `canonical`, Open Graph, `robots.txt`, `sitemap.xml`. Best Practices: `rel="noopener noreferrer"`.
- CI/CD: `.github/workflows/deploy.yml` — job `validate` перевіряє файли й посилання, job `deploy` публікує на Vercel через Vercel CLI (секрет `VERCEL_TOKEN`); автодеплой Vercel із Git вимкнено у `vercel.json`, щоб сайт публікувався один раз.
